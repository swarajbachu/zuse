Every workspace surface follows the active chat environment. If the chat owns a worktree, its file tree, editor, terminal, changes, and pull-request state all point to that checkout.

- [Files and editor](/workspace/files-editor) — browse, preview, edit, and save.
- [Terminal](/workspace/terminal-browser) — run project commands in the active checkout.
- [In-app browser](/workspace/browser) — inspect, debug, annotate, and verify the running app with an agent.
- [Changes and pull requests](/workspace/changes-pull-requests) — review and ship the branch.
