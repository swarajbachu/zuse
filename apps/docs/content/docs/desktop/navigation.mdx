## Projects panel

The left panel groups chats under their project. Select a chat to restore its tabs and environment. Use **New chat** for a new task, and **Open project…** to add a repository or folder.

## Session tabs

Tabs at the top of a chat represent provider sessions. Use a new tab when you want another agent or a clean context inside the same task and checkout. Closing a tab ends that visible session tab; it does not delete the chat's repository work.

## Main tabs

The main area can show the conversation, an opened file, **Changes**, or pull-request content. Opening a file does not replace the chat: use the tab strip to move back.

## Workspace panel

The right panel contains the file tree and terminal. File paths and terminal working directories follow the active chat environment, including its worktree.

## Settings

Open settings with the application menu or `⌘,`. Global sections cover the app, providers, devices, browser, keybindings, diagnostics, and integrations. Selecting a project also exposes repository-specific settings.

See [Keybindings](/reference/keybindings) for every customizable command.
