The desktop app brings the agent conversation and the active checkout into one workspace. Its layout has three persistent zones:

- the **projects panel** for projects and chats;
- the **main area** for session tabs, chat, files, changes, and pull-request context;
- the **workspace panel** for the file tree and terminal.

Panes are resizable and can be hidden with commands or keybindings. The top bar follows the active chat's branch and pull-request state, so the primary action changes from run, to commit, to push, to create or complete a pull request.
